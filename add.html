Track code helper

Add a track to your music player without hand-writing code. Fill in the form, copy the code it makes, and paste it into index.html.

Where the code goes

Open index.html on GitHub (click the file, then the pencil icon). Near the top is the track list. This shows the three spots you’ll paste into:

const T = {
  ← A  your new track line goes here, directly under this line
  void: { … },
};

const ALBUMS = [
  ← C  a brand-new album goes here, directly under this line
  { name: 'Lux Novus', art: '…', tracks: [T.void, T.ash, T.newtrack] },
];                          ↑ B  add to an existing album or playlist

const PLAYLISTS = [
  ← C  a brand-new playlist goes here, directly under this line
  { name: 'Motifs', tracks: [T.void, T.ash, T.newtrack] },
];
  1. Use the form below. The code it makes is labelled A, B or C to match the map above.
  2. Copy each block and paste it where it says. Tip: use Ctrl or Cmd+F in the editor to find const T = {.
  3. Click Commit changes. The site updates in about a minute, so refresh it to see the track.
