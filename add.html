Track code helper

Add a track to your music player without hand-writing code. Fill in the form, copy the code it makes, and paste it into library.json.

Where the code goes

Open library.json on GitHub (click the file, then the pencil icon). This shows the spots you’ll paste into:

{
  "tracks": {
    ← A  your new track line goes here, directly under this line
    "void": { … },
  },
  "albums": [
    ← C  a brand-new album goes here, directly under this line
    { "name": "Lux Novus", "art": "…", "tracks": ["void", "ash", "newtrack"] },
  ],                         ↑ B  add to an existing album or playlist
  "playlists": [
    ← C  a brand-new playlist goes here, directly under this line
    { "name": "Motifs", "tracks": ["void", "ash", "newtrack"] }
  ]
}
  1. Use the form below. The code it makes is labelled A, B or C to match the map above.
  2. Copy each block and paste it where it says. Tip: use Ctrl or Cmd+F in the editor to find the line.
  3. Click Commit changes, wait about a minute, then refresh the player. If it says it couldn’t load library.json, a comma or quote is out of place.
